先確認安全，再釐清症狀

限18歲以上成人。依訪談填寫；尚未確認的資料不會當作正常。

頻繁擔心，還是突然恐慌？

可複選，評估可能共病。

評估結果需由醫療人員確認。

把症狀與時間放在一起看

請逐項詢問；確認訪談後，未勾選的項目表示目前不符合。

完成鑑別，才進入治療

依線索安排生命徵象、心肺與神經學檢查。心悸／昏厥考慮ECG，疑甲亢查TSH，疑低血糖查血糖；按病史考慮CBC、電解質與腎功能，無需人人常規做全部檢驗。回顧咖啡因、能量飲料、興奮劑、類固醇、甲狀腺素，以及酒精／鎮靜安眠藥減停。
不想要的強迫性傷害意念不等同有傷害意圖。仍應分開詢問意圖、計畫、行為與目前安全。

可收合診療心智圖

安全與鑑別 → 分流照護

急性身體警訊／立即傷害風險 → 急診；安全未確認 → 先評估。檢視甲亢、心律不整、低血糖、藥物／戒斷、躁症及精神病。

GAD：長期多領域擔心

≥6個月、多數日子、難以控制＋≥3伴隨症狀＋痛苦／影響 → 階梯照護 → CBT／應用放鬆或SSRI → 症狀與功能追蹤。

恐慌症：非預期反覆發作

數分鐘達峰、≥4症狀、反覆非預期發作＋≥1個月擔心／行為改變 → 恐慌焦點CBT或SSRI → 發作、迴避與功能追蹤。

OCD：侵入性意念或儀式

每日>1小時或明顯痛苦／影響 → ERP或SSRI，嚴重者合併 → 家庭配合儀式、功能與Y-BOCS追蹤。

沒有改善時，先檢查什麼？

重評診斷與共病 → 核對配合度、有效劑量與療程 → 確認心理治療包含ERP／暴露與作業 → 共同討論調整。充分SSRI與ERP仍不足的OCD，轉專科討論換SSRI／clomipramine或增強治療，不在本工具自動加藥。

日常練習與復發預防

規律睡眠、運動與減少咖啡因。ERP與治療師一起訂階層，循序接觸焦慮情境、減少儀式及尋求保證；不進行真實危險或違反感染管制的暴露。恐慌當下先確認安全，以自然緩慢呼吸與地面感受協助穩定，避免紙袋呼吸。記錄早期復發訊號，訂立回診計畫。
